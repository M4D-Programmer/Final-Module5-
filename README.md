# Local Car Lot — Marketplace (Static)

Simple responsive static site demo for a local automotive marketplace. Files:

- index.html — main site
- css/styles.css — styles
- js/app.js — frontend logic (loads data/cars.json)
- data/cars.json — sample inventory

How to run

1. Open `index.html` in a modern browser. For full experience, serve via a local static server to avoid fetch CORS issues.

Example using Python 3:

```bash
python -m http.server 8000
# then open http://localhost:8000
```

Or use the VS Code Live Server extension.
